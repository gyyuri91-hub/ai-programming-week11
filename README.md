# 성적 관리 프로그램 (ai-programming-week11)

## 1. 무엇을 하나요 (What)
성적 CSV 파일을 읽어 유효한 점수(0~100점)와 잘못된 행을 구분해 반환하는 프로그램입니다.

## 2. 왜 만들었나요 (Why)
실제 성적 파일에는 빈 줄, 0~100점을 벗어난 점수, 숫자가 아닌 값, 쉼표가 포함된 이름 등이 섞여 있어 그냥 읽으면 프로그램이 오류로 멈추기 때문입니다.

## 3. 어떻게 쓰나요 (How)
먼저 테스트 및 커버리지 도구를 설치합니다.
